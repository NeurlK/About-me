### :hammer_and_wrench: Projects

The projects I have worked on, where most of the contribution is mine:

1. https://github.com/tradingview/charting-library-tutorial  
   A tutorial project for working with TradingView Charting Library integrations.

2. https://github.com/danielg-tv/stats-export-dashboard  
   Live site: https://stats-export-dashboard-frontend.onrender.com/

   This one started as an internal support-team problem: we had Jira data, but not enough visibility into what it actually tells us.

   With the help of GenAI tools, I built the dashboard from scratch to explore support benchmarks like ticket volume, SLA performance, top requestors, components, labels, escalations, docs outcomes, and how support load changes over time.

   It is also a personal experiment in using AI not just for snippets, but for the whole flow: planning, implementation, debugging, UI decisions, and turning a vague idea into something usable.
